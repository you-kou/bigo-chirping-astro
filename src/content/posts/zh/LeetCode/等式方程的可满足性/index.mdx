<Callout type="info" title="题目描述">

给定一个由表示变量之间关系的字符串方程组成的数组，每个字符串方程 `equations[i]` 的长度为 `4`，并采用两种不同的形式之一：`"a==b"` 或 `"a!=b"`。在这里，a 和 b 是小写字母（不一定不同），表示单字母变量名。

只有当可以将整数分配给变量名，以便满足所有给定的方程时才返回 `true`，否则返回 `false`。

**示例 1：**

```
输入：["a==b","b!=a"]
输出：false
解释：如果我们指定，a = 1 且 b = 1，那么可以满足第一个方程，但无法满足第二个方程。没有办法分配变量同时满足这两个方程。
```

**示例 2：**

```
输入：["b==a","a==b"]
输出：true
解释：我们可以指定 a = 1 且 b = 1 以满足满足这两个方程。
```

**示例 3：**

```
输入：["a==b","b==c","a==c"]
输出：true
```

**示例 4：**

```
输入：["a==b","b!=c","c==a"]
输出：false
```

**示例 5：**

```
输入：["c==c","b==d","x!=z"]
输出：true
```

**提示：**

1. `1 <= equations.length <= 500`
2. `equations[i].length == 4`
3. `equations[i][0]` 和 `equations[i][3]` 是小写字母
4. `equations[i][1]` 要么是 `'='`，要么是 `'!'`
5. `equations[i][2]` 是 `'='`

</Callout>

这道题可以通过 **并查集（Union-Find）** 数据结构高效解决。

## 核心思路

1. **关系抽象**：
   - `a == b` 表示变量 `a` 和 `b` 属于同一个集合（具有连通性）。
   - `a != b` 表示变量 `a` 和 `b` 不能属于同一个集合。
2. **两阶段处理**：
   - **第一步（合并）**：先遍历所有 **`==`** 的方程，将相等的变量合并到同一个集合中。
   - **第二步（校验）**：再遍历所有 **`!=`** 的方程，检查不等号两侧的变量是否在同一个集合中。如果已经在同一个集合中，说明存在矛盾，直接返回 `false`；若全部检查完毕均无冲突，则返回 `true`。

## 参考代码

```c++
class Solution {
private:
    int parent[26];

    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]); // 路径压缩
        }
        return parent[x];
    }

    void unionSet(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        if (rootX != rootY) {
            parent[rootX] = rootY;
        }
    }

public:
    bool equationsPossible(vector<string>& equations) {
        // 1. 初始化并查集，每个字母的根节点初始为自己
        for (int i = 0; i < 26; ++i) {
            parent[i] = i;
        }

        // 2. 第一遍遍历：处理所有 '==' 方程，合并连通分量
        for (const string& eq : equations) {
            if (eq[1] == '=') {
                int var1 = eq[0] - 'a';
                int var2 = eq[3] - 'a';
                unionSet(var1, var2);
            }
        }

        // 3. 第二遍遍历：处理所有 '!=' 方程，校验是否存在矛盾
        for (const string& eq : equations) {
            if (eq[1] == '!') {
                int var1 = eq[0] - 'a';
                int var2 = eq[3] - 'a';
                if (find(var1) == find(var2)) {
                    return false; // 不等号两侧变量在同一集合，矛盾
                }
            }
        }

        return true;
    }
};
```

## 复杂度分析

- **时间复杂度**：$O(N \cdot \alpha(C))$，其中 $N$ 是方程数组 `equations` 的长度，$C = 26$ 是字母表大小。包含路径压缩的并查集操作近乎 $O(1)$，因此整体时间复杂度接近 $O(N)$。
- **空间复杂度**：$O(C)$，只需要固定大小为 26 的数组用于保存父节点信息。
