**树的遍历（Tree Traversal）** 是指按照某种特定的顺序，访问树中所有的节点，且**每个节点恰好被访问一次**。

在二叉树中，遍历算法主要分为两大类：
1. **深度优先遍历（DFS）**：沿着树的深度遍历节点，尽可能深地搜索树的分支。分为**前序**、**中序**和**后序**。
2. **广度优先遍历（BFS）**：按层级由近及远地探索节点。即**层序遍历**。

## 数据结构定义

在 C++ 中，二叉树使用结构体配合指针来实现：

```c++
#include <iostream>

// 定义二叉树节点
struct TreeNode {
    int val;            // 节点存放的数据
    TreeNode* left;     // 指向左子节点的指针
    TreeNode* right;    // 指向右子节点的指针

    // 构造函数：初始化节点值，左右指针默认为空
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
```

## 前序遍历

前序遍历（Pre-order Traversal）遵循 **“根节点 $\rightarrow$ 左子树 $\rightarrow$ 右子树”** 的顺序。每到一个节点，**先立即访问当前节点**，然后再递归地进入左子树，待左子树完全遍历结束后，最后进入右子树。

**参考代码**

```c++
// 前序遍历（递归版）
void preOrder(TreeNode* root) {
    if (root == nullptr) return; // 1. 递归出口：到达空节点

    std::cout << root->val << " "; // 2. 访问当前根节点
    preOrder(root->left);          // 3. 递归遍历左子树
    preOrder(root->right);         // 4. 递归遍历右子树
}
```

## 中序遍历

中序遍历（In-order Traversal）遵循 **“左子树 $\rightarrow$ 根节点 $\rightarrow$ 右子树”** 的顺序。一路向左深入，直到找不到左子节点为止；然后**访问当前节点**；最后进入当前节点的右子树。

**参考代码**

```c++
// 中序遍历（递归版）
void inOrder(TreeNode* root) {
    if (root == nullptr) return; // 1. 递归出口

    inOrder(root->left);           // 2. 递归遍历左子树
    std::cout << root->val << " "; // 3. 访问当前根节点
    inOrder(root->right);          // 4. 递归遍历右子树
}
```

## 后序遍历

后序遍历（Post-order Traversal）遵循 **“左子树 $\rightarrow$ 右子树 $\rightarrow$ 根节点”** 的顺序。只有当当前节点的**左子树和右子树都完全处理完毕后**，才会访问当前节点本身。

</figure>

**参考代码**

```c++
// 后序遍历（递归版）
void postOrder(TreeNode* root) {
    if (root == nullptr) return; // 1. 递归出口

    postOrder(root->left);         // 2. 递归遍历左子树
    postOrder(root->right);        // 3. 递归遍历右子树
    std::cout << root->val << " "; // 4. 访问当前根节点
}
```

## 层序遍历

层序遍历（Level-order Traversal / BFS）属于广度优先搜索（BFS），遵循 **“从上到下，从左到右”** 按层逐个访问节点的顺序。借助 **队列（`std::queue`）** 的“先进先出（FIFO）”特性。先把根节点入队，随后循环弹出队首元素并访问，同时将其非空的左右子节点顺次推入队列中。

</figure>

**参考代码**

```c++
#include <queue>

// 层序遍历（借助队列实现）
void levelOrder(TreeNode* root) {
    if (root == nullptr) return; // 树为空直接返回

    std::queue<TreeNode*> q;     // 创建辅助队列
    q.push(root);                // 1. 将根节点入队

    while (!q.empty()) {
        TreeNode* curr = q.front(); // 获取队首节点
        q.pop();                    // 弹出队首节点

        std::cout << curr->val << " "; // 2. 访问当前节点

        // 3. 将左右孩子依次推入队列，等待后续按层处理
        if (curr->left != nullptr) {
            q.push(curr->left);
        }
        if (curr->right != nullptr) {
            q.push(curr->right);
        }
    }
}
```
