<Callout type="info" title="题目描述">
自幂数是指，一个 $N$ 位数，满足各位数字 $N$ 次方之和是本身。例如，$153$ 是 $3$ 位数，其每位数的 $3$ 次方之和，$1^3+5^3+3^3=153$，因此 $153$ 是自幂数；$1634$ 是 $4$ 位数，其每位数的 $4$ 次方之和，$1^4+6^4+3^4+4^4=1634$，因此 $1634$ 是自幂数。

现在，输入若干个正整数，请判断它们是否是自幂数。

**输入格式**

输入第一行是一个正整数 $M$，表示有 $M$ 个待判断的正整数。约定 $1 \le M \le 100$。

从第 $2$ 行开始的 $M$ 行，每行一个待判断的正整数。约定这些正整数均小于 $10^8$。

**输出格式**

输出 $M$ 行，如果对应的待判断正整数为自幂数，则输出英文大写字母 $\texttt T$，否则输出英文大写字母 $\texttt F$。

提示：不需要等到所有输入结束在依次输出，可以输入一个数就判断一个数并输出，再输入下一个数。

**样例**

**输入样例 1**

  ```
3
152
111
153
  ```

**输出样例 1**

  ```
F
F
T
  ```

**输入样例 2**

  ```
5
8208
548834
88593477
12345
5432
  ```

**输出样例 2**

  ```
T
T
T
F
F
  ```

## 解题思路

1. **确定位数 $N$**：求出当前正整数的位数 $N$（可以转成字符串求长度，或通过不断除以 $10$ 统计位数）。
2. **计算各位数字的 $N$ 次方和**：逐位取出数字，求该数字的 $N$ 次方（或用循环连乘 $N$ 次），并累加到总和中。
3. **判断并输出**：比较累加和与原数值是否相等，相等则输出 `T`，否则输出 `F`。

在具体实现时，有两种常见的处理方式：

**方法一：字符串转化法（直观易写）**

将输入的数字直接作为字符串 `string` 读入：

- **位数 $N$**：即为字符串长度 `s.length()`。
- **按位提取**：遍历字符串的每个字符 `c`，用 `c - '0'` 转化为对应数字。
- **注意点**：需要用 `stoll` 将原字符串转为整数，用于最后的相等判断。

**方法二：纯数学取模法（基础数论）**

直接将数值作为整数 `long long` 读入，通过数字运算处理：

- **位数 $N$**：利用 `while (temp > 0)` 循环不断 `temp /= 10`，统计相除的次数。
- **按位提取**：利用 `temp % 10` 取出当前最低位，再通过 `temp /= 10` 剥离最低位，依次累加其 $N$ 次方。

## 参考代码

### 方法一：字符串解析法

```c++
#include <iostream>
#include <string>
#include <cmath>

using namespace std;

void solve() {
    string s;
    cin >> s;

    int n = s.length(); // 获取位数 N
    long long original = stoll(s); // 转为整数便于最后比较
    long long sum = 0;

    // 计算每位数字的 N 次方之和
    for (char c : s) {
        int digit = c - '0';
        sum += round(pow(digit, n)); // 使用 round 防止浮点数精度误差
    }

    // 判断并输出结果
    if (sum == original) {
        cout << "T" << endl;
    } else {
        cout << "F" << endl;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int m;
    cin >> m;
    while (m--) {
        solve();
    }

    return 0;
}
```

### 方法二：纯数学计算法

```c++
#include <iostream>
#include <cmath>

using namespace std;

void solve() {
    long long x;
    cin >> x;

    long long temp = x;
    int n = 0;

    // 1. 统计位数 N
    while (temp > 0) {
        n++;
        temp /= 10;
    }

    // 2. 取每位数字并计算 N 次方之和
    temp = x;
    long long sum = 0;
    while (temp > 0) {
        int digit = temp % 10; // 取当前最低位数字
        sum += round(pow(digit, n)); // 使用 round 避免浮点数精度误差
        temp /= 10; // 抹掉最低位
    }

    // 3. 判断并输出结果
    if (sum == x) {
        cout << "T\n";
    } else {
        cout << "F\n";
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int m;
    cin >> m;
    while (m--) {
        solve();
    }

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\mathcal{O}(M \times \log_{10} X)$。对于每个待测数字 $X$，提取位数和按位计算的次数等于 $X$ 的十进制位数（最高为 $8$ 位）。在 $M \le 100$ 的数据范围内，总计算量不超过 $10^3$ 次，轻松在 $1.00\text{s}$ 内通过。
- **空间复杂度**：$\mathcal{O}(1)$。仅占用常数级别的临时变量空间。
