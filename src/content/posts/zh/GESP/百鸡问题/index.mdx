<Callout type="info" title="题目描述">

“百鸡问题”是出自我国古代《张丘建算经》的著名数学问题。大意为：“每只公鸡 $5$ 元，每只母鸡 $3$ 元，每 $3$ 只小鸡 $1$ 元；现在有 $100$ 元，买了 $100$ 只鸡，共有多少种方案？”

小明很喜欢这个故事，他决定对这个问题进行扩展，并使用编程解决：如果每只公鸡 $x$ 元，每只母鸡 $y$ 元，每 $z$ 只小鸡 $1$ 元；现在有 $n$ 元，买了 $m$ 只鸡，共有多少种方案？

**输入格式**

输入一行，包含五个整数，分别为问题描述中的 $x$，$y$，$z$，$n$，$m$。约定 $1 \le x,y,z \le 10$，$1 \le n,m \le 1000$。

**输出格式**

输出一行，包含一个整数 $C$，表示有 $C$ 种方案。

**样例**

**输入样例 1**

  ```
5 3 3 100 100
  ```

**输出样例 1**

  ```
4
  ```

**输入样例 2**

  ```
1 1 1 100 100
  ```

**输出样例 2**

  ```
5151
  ```

**样例 1 解释**

  这就是问题描述中的“百鸡问题”。$4$ 种方案分别为：
  - 公鸡 $0$ 只、母鸡 $25$ 只、小鸡 $75$ 只。
  - 公鸡 $4$ 只、母鸡 $18$ 只、小鸡 $78$ 只。
  - 公鸡 $8$ 只、母鸡 $11$ 只、小鸡 $81$ 只。
  - 公鸡 $12$ 只、母鸡 $4$ 只、小鸡 $84$ 只。
</Callout>

## 思路分析

1. **变量定义**：
   - 设购买公鸡 $a$ 只（每只 $x$ 元）、母鸡 $b$ 只（每只 $y$ 元）、小鸡 $c$ 只（每 $z$ 只 $1$ 元）。
   - 需要满足两个条件：
     1. 总数量：$a + b + c = m$
     2. 总金额：$a \times x + b \times y + \frac{c}{z} = n$
2. **枚举优化**：
   - 范围限制：数据范围 $n, m \le 1000$，且 $x, y, z \ge 1$。如果使用三重循环枚举 $a, b, c$ 会超时（$O(m^3)$）。
   - 双重循环优化：由于 $a + b + c = m$，只需要通过两重循环枚举公鸡数量 $a$ 和母鸡数量 $b$，即可直接算出小鸡数量 $c = m - a - b$。这样时间复杂度降为 $O(m^2)$，在 $1.00\text{s}$ 内可以轻松通过。
3. **判定条件**：
   - 小鸡数量 $c$ 必须是非负整数：$c \ge 0$。
   - 小鸡必须能按套（每 $z$ 只 $1$ 元）整买：即 $c$ 必须是 $z$ 的倍数（`c % z == 0`）。
   - 总花费必须刚好等于 $n$：`a * x + b * y + c / z == n`。

## 参考代码

```c++
#include <iostream>

using namespace std;

int main() {
    // 提高输入输出效率
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int x, y, z, n, m;
    if (!(cin >> x >> y >> z >> n >> m)) return 0;

    int ans = 0; // 记录方案数

    // 枚举公鸡数量 a
    for (int a = 0; a * x <= n && a <= m; ++a) {
        // 枚举母鸡数量 b
        for (int b = 0; a * x + b * y <= n && a + b <= m; ++b) {
            int c = m - a - b; // 计算小鸡数量

            // 验证小鸡数量是否能被 z 整除，且总钱数刚好为 n
            if (c % z == 0 && (a * x + b * y + c / z == n)) {
                ans++;
            }
        }
    }

    cout << ans << "\n";

    return 0;
}
```
